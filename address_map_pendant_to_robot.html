펜던트 → 로봇 주소 맵

펜던트에서 로봇으로 전송되는 제어 명령 및 설정값

주소 범위: 161 ~ 255
레지스터 수: 95개
데이터 방향: Read/Write
업데이트: 변경 시

통신 제어

주소 신호명 데이터 타입 범위/값 단위 설명
161 펜던트 하트비트 UINT16 0 ~ 500 - 펜던트 통신 상태 확인용 카운터. 500 도달 시 0으로 리셋
240 로봇 반환 완료 UINT16 0 / 1 - 1: 반환 (로봇 요청 ADDR 154 받으면 0으로 변경)

Python 쓰기 예제

from pymodbus.client import ModbusTcpClient

client = ModbusTcpClient('192.168.1.7', port=502)
client.connect()

# 작업 모드 설정 (자동 모드)
client.write_register(address=162, value=2, unit=1)

# 용접 조건 설정
voltage = int(25.5 * 10)  # 25.5V → 255
current = 180  # 180A
client.write_register(address=231, value=voltage, unit=1)
client.write_register(address=232, value=current, unit=1)

# 치수 정보 설정
dimensions = [150, 200, 100]  # 수직좌, 수직우, 수평 (mm)
client.write_registers(address=173, values=dimensions, unit=1)

print("✓ 펜던트 설정값 전송 완료")

client.close()
⚠️

주의사항

  • 하트비트(ADDR 161)는 0~500 범위로 순환하며, 500 도달 시 0으로 리셋됩니다
  • 전압 데이터는 0.1V 단위로 스케일링되어 있으므로 10을 곱해서 전송하세요
  • 치수 정보는 mm 단위로 직접 입력합니다
  • 작업 모드 변경 시 로봇 상태를 먼저 확인하세요
