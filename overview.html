시스템 개요

조선소 용접 자동화 시스템 구성

1. 시스템 구성

조선소 용접 자동화 시스템은 다음 3가지 주요 컴포넌트로 구성됩니다:

🤖

UR 협동로봇

  • Universal Robot (UR3/UR5/UR10)
  • 용접 토치 제어
  • 경로 계획 및 실행
  • 안전 모니터링
📱

용접 제어 펜던트

  • 용접 조건 설정
  • 작업 모드 선택
  • 치수 입력 및 관리
  • 용접 파라미터 조정
⚡

용접기

  • 용접 전원 공급
  • 전류/전압 제어
  • 와이어 송급
  • 보호가스 공급

2. 통신 구조

┌─────────────────────────────────────────────────────────┐
│                                                         │
│                   Ethernet Network                      │
│                   (192.168.1.x/24)                      │
│                                                         │
└────────────┬──────────────┬─────────────┬──────────────┘
             │              │             │
   ┌─────────▼────────┐ ┌──▼─────────┐ ┌─▼──────────────┐
   │   UR 협동로봇     │ │  용접 제어  │ │   용접기        │
   │                  │ │  펜던트     │ │                │
   │  IP: 192.168.1.7 │ │ IP: Custom  │ │ IP: 192.168.1.2│
   │  Port: 502       │ │             │ │ Port: 502      │
   │                  │ │             │ │                │
   │ Modbus TCP Slave │ │  제어 UI    │ │ Modbus Master  │
   └──────────────────┘ └─────────────┘ └────────────────┘

💡 통신 흐름

  1. 로봇 ↔ 펜던트: 작업 정보, 용접 조건, 상태 모니터링
  2. 로봇 ↔ 용접기: 용접 제어 명령, 피드백 데이터
  3. 모든 장치: 실시간 하트비트로 통신 상태 확인

3. Modbus TCP 주소 구조

🤖 → 📱 로봇 to 펜던트

ADDR: 128 ~ 160
주소 신호명 설명
128 하트비트 로봇 통신 상태
129 프로그램 동작여부 1=동작, 0=정지
130 용접 여부 1=용접중, 0=대기
131~132 현재 전류/전압 실시간 용접 상태
160 로봇 버전 메이저.마이너.버그

📱 → 🤖 펜던트 to 로봇

ADDR: 161 ~ 255
주소 신호명 설명
161 펜던트 하트비트 0~500
162 작업 모드 1=수동, 2=자동
173~175 수직좌/우, 수평 치수 정보 (mm)
231~232 전압/전류 용접 조건

🤖 → ⚡ 로봇 to 용접기

ADDR: 201 ~ 210
주소 신호명 설명
201 로봇 사용 용접기 제어 권한
202 용접기 제어 ON/OFF 명령
204~205 전류/전압 설정 용접 조건 설정
207~210 호선/블록 번호 작업 식별 정보

⚡ → 🤖 용접기 to 로봇

ADDR: 211 ~ 223
주소 신호명 설명
211 용접기 하트비트 통신 상태 확인
212~213 전류/전압 피드백 실제 출력값
214 송급장치 상태 와이어 송급 속도
216 용접기 오류 에러 코드 0~255

4. 데이터 교환 시나리오

시나리오 1: 용접 작업 시작

1
펜던트 → 로봇: 작업 모드 설정 (ADDR 162 = 2, 자동모드)
2
펜던트 → 로봇: 용접 조건 전송 (전류, 전압, 치수 정보)
3
로봇 → 용접기: 용접기 제어 ON (ADDR 202 = 1)
4
로봇 → 용접기: 전류/전압 설정값 전송
5
용접기 → 로봇: 실시간 전류/전압 피드백
6
로봇 → 펜던트: 용접 상태 및 실시간 데이터 전송

시나리오 2: 에러 발생 및 처리

⚠️
용접기 → 로봇: 오류 코드 발생 (ADDR 216 ≠ 0)
2
로봇: 용접 중단, 안전 정지
3
로봇 → 펜던트: 로봇 에러 플래그 전송 (ADDR 142)
4
펜던트: 에러 표시 및 사용자 알림

5. 시스템 특징

💓

하트비트 모니터링

모든 장치는 주기적으로 하트비트 신호를 교환하여 통신 상태를 실시간 확인

🔄

양방향 통신

로봇-펜던트, 로봇-용접기 간 실시간 데이터 교환으로 정밀한 용접 제어

⚡

실시간 피드백

용접 전류/전압의 실시간 피드백으로 용접 품질 모니터링

🛡️

안전 기능

토치 충돌 감지, 비상정지, 보안정지 등 다중 안전 메커니즘

📊

데이터 로깅

모든 용접 파라미터 및 상태 정보를 기록하여 품질 추적 가능

🔧

유연한 설정

다양한 용접 조건 및 파라미터를 펜던트를 통해 간편하게 조정

ℹ️
