하드웨어 연결 및 네트워크 설정 방법

1. 시스템 구성도

2. 하드웨어 연결

2.1 필요 장비

🤖

UR 협동로봇

  • UR3 / UR5 / UR10
  • URCap 소프트웨어 설치 필요
  • 이더넷 포트: RJ45
⚡

Hi-COMM Ethernet

  • 용접기 제어 컨버터
  • Modbus TCP Master 기능
  • 이더넷 포트: RJ45
🔌

네트워크 장비

  • 이더넷 케이블 (Cat5e 이상)
  • 네트워크 스위치 (선택사항)
  • PC (설정 및 모니터링용)

2.2 물리적 연결

1

UR 로봇 이더넷 연결

UR 로봇 컨트롤 박스의 이더넷 포트에 케이블 연결

  • 케이블 규격: Cat5e 이상
  • 최대 케이블 길이: 100m
  • 커넥터: RJ45
2

Hi-COMM Ethernet 연결

Hi-COMM Ethernet의 이더넷 포트에 케이블 연결

  • 용접기와 CAN 통신 연결 확인
  • 전원 공급 확인 (DC 24V)
3

네트워크 스위치 연결 (선택)

여러 장치를 연결할 경우 스위치 사용

  • PoE 미지원 스위치 권장
  • 10/100 Mbps 지원
4

LED 상태 확인

각 장치의 이더넷 LED 확인

  • Link LED: 녹색 점등 (연결됨)
  • Activity LED: 깜빡임 (데이터 전송 중)

3. UR 로봇 네트워크 설정

3.1 티칭 팬던트에서 설정

단계 1: UR 티칭 팬던트 전원 ON
단계 2: 메인 화면에서 설정 메뉴 선택
단계 3: 시스템 → 네트워크 선택
단계 4: IP 설정 변경 
IP 주소: 192.168.1.7
서브넷 마스크: 255.255.255.0
게이트웨이: 192.168.1.1
DNS: (필요시 설정)
단계 5: 적용 버튼 클릭
단계 6: 로봇 재부팅 (설정 적용)

💡 IP 주소 변경 시 주의사항

  • Hi-COMM Ethernet와 동일한 서브넷에 설정해야 합니다
  • IP 주소 충돌이 없는지 확인하세요 (ping 테스트)
  • 변경 후 반드시 재부팅하여 설정을 적용하세요

4. Hi-COMM Ethernet 네트워크 설정

4.1 설정 도구 사용

Hi-COMM Ethernet의 IP 주소는 전용 설정 도구를 통해 변경합니다.

⚠️

설정 방법

Hi-COMM Ethernet의 IP 설정 변경은 제조사 제공 설정 도구를 사용해야 합니다.

자세한 내용은 "Hi-COMM Ethernet Device Description Sheet" 문서를 참조하세요.

4.2 기본 네트워크 설정

IP 주소: 192.168.1.2 (기본값)
서브넷 마스크: 255.255.255.0
게이트웨이: 192.168.1.1
Modbus TCP 포트: 502

5. 통신 테스트

5.1 Ping 테스트

Windows/Linux PC에서 테스트

# UR 로봇 연결 테스트
ping 192.168.1.7

# 성공 시 출력:
Reply from 192.168.1.7: bytes=32 time<1ms TTL=64

# Hi-COMM Ethernet 연결 테스트
ping 192.168.1.2

# 성공 시 출력:
Reply from 192.168.1.2: bytes=32 time<1ms TTL=64

5.2 포트 확인

Telnet으로 Modbus TCP 포트 확인

# Windows
telnet 192.168.1.7 502

# Linux/Mac
telnet 192.168.1.7 502

# 또는 nc (netcat) 사용
nc -zv 192.168.1.7 502

# 성공 시 출력:
Connection to 192.168.1.7 port 502 [tcp/*] succeeded!

5.3 Python으로 Modbus 연결 테스트

from pymodbus.client import ModbusTcpClient

# 연결 테스트
print("UR 로봇 연결 테스트...")
client = ModbusTcpClient('192.168.1.7', port=502)

if client.connect():
    print("✓ UR 로봇 연결 성공")
    
    # 로봇 모드 읽기 테스트
    result = client.read_input_registers(address=258, count=1, unit=1)
    if not result.isError():
        robot_mode = result.registers[0]
        modes = {0: "Disconnected", 5: "Idle", 7: "Running"}
        print(f"  로봇 모드: {modes.get(robot_mode, f'Unknown({robot_mode})')}")
    
    client.close()
else:
    print("✗ UR 로봇 연결 실패")
    print("  - IP 주소 확인")
    print("  - 케이블 연결 확인")
    print("  - 방화벽 설정 확인")

6. 방화벽 설정

6.1 Windows 방화벽

방법 1: GUI 설정

  1. 제어판 → Windows Defender 방화벽
  2. 고급 설정 클릭
  3. 인바운드 규칙 → 새 규칙
  4. 포트 → TCP → 특정 로컬 포트: 502
  5. 연결 허용 → 모든 프로필 → 이름: "Modbus TCP"

방법 2: PowerShell (관리자 권한)

New-NetFirewallRule -DisplayName "Modbus TCP" `
    -Direction Inbound `
    -Protocol TCP `
    -LocalPort 502 `
    -Action Allow

6.2 Linux 방화벽 (iptables)

# Modbus TCP 포트 허용
sudo iptables -A INPUT -p tcp --dport 502 -j ACCEPT
sudo iptables -A OUTPUT -p tcp --sport 502 -j ACCEPT

# 설정 저장 (Ubuntu/Debian)
sudo iptables-save | sudo tee /etc/iptables/rules.v4

# 또는 firewalld 사용 (CentOS/RHEL)
sudo firewall-cmd --permanent --add-port=502/tcp
sudo firewall-cmd --reload

7. URCap 설치 (선택사항)

📦 URCap이란?

URCap은 UR 로봇의 기능을 확장하는 플러그인입니다. 용접 자동화를 위한 전용 URCap을 설치하면 더 편리하게 사용할 수 있습니다.

7.1 URCap 설치 절차

1

URCap 파일 준비

용접 시스템 전용 URCap 파일(.urcap) 다운로드

2

USB 드라이브 복사

.urcap 파일을 USB 드라이브에 복사

3

UR 로봇에 연결

USB 드라이브를 UR 컨트롤 박스에 연결

4

URCap 설치

티칭 팬던트: 설정 → URCaps → + 버튼

USB에서 .urcap 파일 선택 후 설치

5

로봇 재부팅

URCap 적용을 위해 로봇 재부팅

8. 트러블슈팅

❌ Ping이 안 됨

원인:
  • 케이블 연결 불량
  • IP 주소 설정 오류
  • 네트워크 장비 문제
해결:
  • 케이블 연결 상태 확인 (LED 점등)
  • IP 주소가 동일 서브넷인지 확인
  • 장비 전원 재시작

❌ Modbus 연결 실패

원인:
  • 포트 502 막힘 (방화벽)
  • 다른 프로그램이 포트 사용 중
  • Modbus 서버 미실행
해결:
  • 방화벽에서 포트 502 허용
  • netstat -an | findstr 502로 포트 사용 확인
  • UR 로봇 재부팅

❌ 데이터 읽기 에러

원인:
  • 잘못된 주소 범위
  • Unit ID 불일치
  • 함수 코드 미지원
해결:
  • 주소 맵 문서 확인
  • Unit ID를 1로 설정
  • 지원하는 함수 코드 사용 (FC 04, 16)

❌ 하트비트 정지

원인:
  • 통신 연결 끊김
  • 로봇 프로그램 정지
  • 네트워크 지연
해결:
  • 네트워크 연결 상태 확인
  • 로봇 프로그램 실행 확인
  • 폴링 주기 확인 (10ms)
