2. Modbus TCP 통신 방식

2.1 통신 구조

Master-Slave 방식

  • Master (Hi-COMM Ethernet): 주기적으로 Slave에게 데이터 요청
  • Slave (UR Robot): Master의 요청에 응답
  • 폴링 주기: 10ms (100Hz)

2.2 지원 함수 코드

함수 코드 이름 용도 사용
04 (0x04) Read Input Registers UR 로봇 → Hi-COMM 데이터 읽기 사용
16 (0x10) Write Multiple Registers Hi-COMM → UR 로봇 데이터 쓰기 사용

3. 레지스터 주소 맵 구조

🎛️

UR I/O

주소: 0 ~ 1

내용: Digital Inputs/Outputs (Tool, Box)

비트 구성: [BBBBBBBBTT xxxxxx]

  • T = Tool I/O (2 bits)
  • B = Box I/O (8 bits)
🤖→📱

로봇 → 펜던트

주소: 128 ~ 160

레지스터 수: 33개

주요 데이터:

  • 하트비트 (128)
  • 용접 상태 (129~130)
  • 전류/전압 피드백 (131~134)
  • PATH 정보 (135~139)
  • 로봇 상태 (141~142)
📱→🤖

펜던트 → 로봇

주소: 161 ~ 255

레지스터 수: 95개

주요 데이터:

  • 작업 모드 (162)
  • 치수 정보 (173~175)
  • 용접 조건 (231~232)
  • 시작/종료 파라미터 (241~255)
🤖→⚡

로봇 → 용접기

주소: 201 ~ 210

레지스터 수: 10개

주요 데이터:

  • 용접기 제어 ON/OFF (202)
  • 전류/전압 설정 (204~205)
  • 호선/블록 번호 (207~210)
⚡→🤖

용접기 → 로봇

주소: 211 ~ 223

레지스터 수: 13개

주요 데이터:

  • 하트비트/상태 (211)
  • 전류/전압 피드백 (212~213)
  • 오류 코드 (216)
  • 용접 파라미터 (220~222)
🤖📡

UR 로봇 시스템

주소: 256 ~ 405

레지스터 수: 150개

주요 데이터:

  • 로봇 모드/안전상태 (258~265)
  • 조인트 각도 (270~275)
  • 조인트 속도 (280~285)
  • 조인트 전류 (290~295)
  • 조인트 온도 (300~305)
  • TCP 위치 (400~405)

4. 데이터 형식

4.1 레지스터 데이터 타입

데이터 타입 크기 표현 범위 예시
UINT16 2 bytes 0 ~ 65535 하트비트, 카운터
INT16 2 bytes -32768 ~ 32767 온도, 보정값
BIT Field 16 bits 각 비트별 의미 I/O 상태, 플래그
Scaled Value 2 bytes 스케일링 적용 전류 (0~600A), 전압 (0.0~80.0V)

4.2 스케일링 규칙

전류 (A)

레지스터 값: 0 ~ 600
실제 값: 0A ~ 600A
변환: 실제값 = 레지스터값 × 1A

전압 (V)

레지스터 값: 0 ~ 800
실제 값: 0.0V ~ 80.0V
변환: 실제값 = 레지스터값 × 0.1V

치수 (mm)

레지스터 값: 0 ~ 1000
실제 값: 0mm ~ 1000mm
변환: 실제값 = 레지스터값 × 1mm

각도 (mrad)

레지스터 값: -32768 ~ 32767
실제 값: mrad (밀리라디안)
변환: 도 = 레지스터값 / 1000 × (180/π)

5. 통신 타이밍

하트비트 메커니즘

시간 →
0ms          10ms         20ms         30ms         40ms
 |            |            |            |            |
 └─ Read ────→└─ Read ────→└─ Read ────→└─ Read ────→
    └→ Resp     └→ Resp     └→ Resp     └→ Resp
    
펜던트 HB:  0 → 1 → 2 → 3 → ... → 499 → 500 → 0 (순환)
로봇 HB:    증가 카운터
용접기 HB:  비트 8에서 토글

💡 하트비트 확인 방법

  • 펜던트 (ADDR 161): 0~500 순환, 변화 없으면 통신 끊김
  • 용접기 (ADDR 211): Bit 8 토글, 추가로 Bit 4(스틱아웃), Bit 5(WCR) 상태
  • 확인 주기: 최소 100ms 이내 변화 확인 권장

6. 에러 처리

6.1 통신 에러

에러 유형 감지 방법 대응
연결 끊김 TCP 소켓 닫힘 재연결 시도 (최대 3회)
타임아웃 응답 시간 > 1초 재요청, 연결 상태 확인
하트비트 정지 하트비트 값 변화 없음 통신 끊김 판단, 재연결
Modbus 예외 예외 응답 수신 에러 코드 확인 후 재시도

6.2 용접 시스템 에러

로봇 에러 (ADDR 142)

  • 0: 정상
  • 1: 에러 발생 (상세 내용은 로봇 로그 확인)

용접기 오류 (ADDR 216)

  • 0: 정상
  • 1~255: 오류 코드 (용접기 매뉴얼 참조)

비상 정지 (ADDR 262)

모든 용접 동작 즉시 중단

🔒

안전 영역 침범 시 1

로봇 동작 정지, 재시작 필요

⚠️

안전 정지 신호 (ADDR 265)

안전 신호 이상 시 1

시스템 전체 정지

💥

토치 충돌 감지

충돌 감지 시 플래그 설정

즉시 용접 중단 및 후퇴

⚠️

안전 정지 발생 시 동작

ADDR 261, 262, 265 중 하나라도 1이면:

  • 토치 동작 명령 (ADDR 202) 강제 OFF
  • 정인칭/역인칭 명령 강제 OFF
  • 가스체크/스틱체크 명령 강제 OFF
