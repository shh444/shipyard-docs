로봇 → 용접기 주소 맵

UR 로봇에서 Hi-COMM Ethernet으로 전송하는 용접 제어 명령

주소 범위: 200 ~ 209
레지스터 수: 10개
통신 방향: Master Read
함수 코드: FC 04 (Read Input Registers)

통신 개요

통신 흐름: UR 로봇(Slave) ← Hi-COMM Ethernet(Master)

주소 시작: Modbus TCP Register Address 200

함수 코드: 04 (Read Input Registers)

폴링 주기: 10ms (100Hz)

ADDR 201: 로봇 사용 가능 여부

주소 신호명 비트 값 설명
201 로봇 사용 Bit 0 0: 사용 불가
1: 사용 가능		 로봇에서 용접기 사용 가능 상태
Bit 1~15 Reserved 향후 확장용

ADDR 202: 용접기 제어 (비트 필드)

주소 비트 신호명 값 설명
202 Bit 0 토치 동작 명령 0: OFF
1: ON		 용접 토치 ON/OFF 제어
Bit 1~3 Reserved - 향후 확장용
Bit 4 가스체크 동작 명령 0: OFF
1: ON		 보호가스 체크 명령
Bit 5 스틱체크 동작 명령 0: OFF
1: ON		 스틱아웃 체크 명령
Bit 6 토치 충돌 검출 상태 0: 미검출
1: 검출		 로봇이 감지한 토치 충돌 상태
Bit 7 로봇 오류 상태 0: 정상
1: 오류		 로봇 시스템 오류 발생
Bit 8 토치 동작 명령 0: OFF
1: ON		 용접 토치 제어 (상위 바이트)
Bit 13 정인칭 동작 명령 0: OFF
1: ON		 정인칭(Forward) 와이어 송급
Bit 14 역인칭 동작 명령 0: OFF
1: ON		 역인칭(Reverse) 와이어 송급

⚠️

안전 정지 시 동작

로봇이 보안 정지(ADDR 261), 비상 정지(ADDR 262), 안전 정지(ADDR 265) 상태일 경우:

  • 토치 동작 명령 (Bit 0, 8) → 강제 OFF
  • 정인칭 명령 (Bit 13) → 강제 OFF
  • 역인칭 명령 (Bit 14) → 강제 OFF
  • 가스체크 명령 (Bit 4) → 강제 OFF
  • 스틱체크 명령 (Bit 5) → 강제 OFF

ADDR 203: 용접 와이어 및 모드 설정 (비트 필드)

주소 비트 신호명 값 설명
203 Bit 0~1 보호가스 설정 00: CO2 100%
01: Ar 80% + CO2 20%
10: Ar 98% + O2 2%
11: Ar 100% 		용접 보호가스 종류
Bit 2~3 용접 시퀀스 모드 00: LSM (저스패터 단락)
01: DCM (일반 단락)
10: DPM (더블 펄스)
11: PM (펄스) 		용접 모드 선택
Bit 4~6 와이어 직경 설정 000: 0.8mm
001: 0.9mm
010: 1.0mm
011: 1.2mm
100: 1.4mm
101: 1.6mm 		용접 와이어 직경
Bit 7~9 와이어 재질 설정 000: FE-Solid
001: FE-Cored
010: STS-Solid
011: STS-Cored
100: AL-Soft
101: AL-Hard
110: CuSi
111: CuMg 		용접 와이어 재질
Bit 10 전압 설정 방식 0: 전류/전압 개별 설정
1: 전류/전압 시너직 설정 		용접 전압 제어 방식

예제: 설정값 읽기

// ADDR 203 레지스터 값: 0b0000010011000001 (0x0CC1)
value = modbus_read(address=203)

// 비트 추출
gas_type = value & 0x03           // Bit 0~1: 01 = Ar 80% + CO2 20%
weld_mode = (value >> 2) & 0x03   // Bit 2~3: 00 = LSM
wire_dia = (value >> 4) & 0x07    // Bit 4~6: 011 = 1.2mm
wire_mat = (value >> 7) & 0x07    // Bit 7~9: 000 = FE-Solid
voltage_mode = (value >> 10) & 0x01 // Bit 10: 0 = 개별 설정

ADDR 204~205: 용접 출력 설정

주소 신호명 데이터 타입 범위 단위 스케일 설명
204 전류 설정 UINT16 30 ~ 400 A × 1A 본 용접 출력 전류 설정값
예: 150 = 150A
205 전압 설정 UINT16 100 ~ 400 V × 0.1V 본 용접 출력 전압 설정값
예: 255 = 25.5V

ADDR 206: 전압 시너직 보정

주소 신호명 데이터 타입 범위 표현 설명
206 전압 시너직 보정 UINT16 0 ~ 100 -5.0 ~ +5.0 시너직 전압 보정값
중심값: 50
예: 70 = (70-50) × 0.1 = +2.0

예제: 시너직 보정 계산

// 레지스터 값에서 실제 보정값 계산
reg_value = modbus_read(address=206)  // 예: 65

center = 50
scale = 0.1
correction = (reg_value - center) * scale

print(f"보정값: {correction:+.1f}")  // +1.5

// 실제 보정값에서 레지스터 값 계산
correction = 2.5  // +2.5V 보정
reg_value = int((correction / scale) + center)  // 75

modbus_write(address=206, value=reg_value)

ADDR 207~210: 작업 정보

주소 신호명 데이터 타입 설명
207 호선 번호 UINT16 조선소 호선(선박) 번호
208 블록 번호 UINT16 블록 식별 번호
209 단위블록 (문자) UINT16 단위 블록 문자 코드
210 단위블록 (숫자) UINT16 단위 블록 숫자 코드

📝 작업 정보 사용 목적

호선/블록/단위블록 정보는 용접 작업의 추적성(Traceability)을 위해 사용됩니다:

  • 용접 데이터 로깅 및 품질 관리
  • 작업 이력 추적
  • 생산 관리 시스템 연동

전체 주소 맵 요약

주소 신호명 데이터 형식 주요 내용
201 로봇 사용 비트 로봇 사용 가능 여부
202 용접기 제어 비트 필드 토치, 정/역인칭, 가스/스틱체크
203 와이어/모드 설정 비트 필드 와이어 재질/직경, 용접 모드
204 전류 설정 UINT16 30~400A
205 전압 설정 UINT16 10.0~40.0V
206 시너직 보정 UINT16 -5.0~+5.0
207~210 작업 정보 UINT16 호선/블록 번호

Python 전체 읽기 예제

from pymodbus.client import ModbusTcpClient

client = ModbusTcpClient('192.168.1.7', port=502)
client.connect()

# 로봇 → 용접기 데이터 읽기 (ADDR 200~209)
result = client.read_input_registers(address=200, count=10, unit=1)

if not result.isError():
    robot_ready = result.registers[1] & 0x01  # ADDR 201 Bit 0
    
    # ADDR 202 제어 비트 추출
    control = result.registers[2]
    torch_on = control & 0x01
    gas_check = (control >> 4) & 0x01
    stick_check = (control >> 5) & 0x01
    torch_collision = (control >> 6) & 0x01
    robot_error = (control >> 7) & 0x01
    forward_feed = (control >> 13) & 0x01
    reverse_feed = (control >> 14) & 0x01
    
    # ADDR 204~205 용접 조건
    current_set = result.registers[4]  # A
    voltage_set = result.registers[5] * 0.1  # V
    
    # ADDR 207~210 작업 정보
    ship_no = result.registers[7]
    block_no = result.registers[8]
    
    print(f"로봇 준비: {'OK' if robot_ready else 'Not Ready'}")
    print(f"토치 상태: {'ON' if torch_on else 'OFF'}")
    print(f"충돌 감지: {'Yes' if torch_collision else 'No'}")
    print(f"설정 전류: {current_set}A")
    print(f"설정 전압: {voltage_set}V")
    print(f"호선 번호: {ship_no}")

client.close()
