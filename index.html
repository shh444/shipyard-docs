주소 맵 요약

🤖→📱

로봇 → 펜던트

주소 범위: 128 ~ 160

주요 신호: 하트비트, 용접상태, 전류/전압, PATH 정보

📱→🤖

펜던트 → 로봇

주소 범위: 161 ~ 255

주요 신호: 작업모드, 용접조건, 치수정보, 파라미터

🤖→⚡

로봇 → 용접기

주소 범위: 201 ~ 210

주요 신호: 용접기 제어, 전류/전압 설정, 호선/블록 정보

⚡→🤖

용접기 → 로봇

주소 범위: 211 ~ 223

주요 신호: 전류/전압 피드백, 송급장치 상태, 오류코드

🤖📡

UR 로봇 시스템

주소 범위: 0~1, 256~405

주요 신호: I/O, 로봇모드, 조인트 각도/속도/전류, TCP 위치

📋

통신 사양

프로토콜: Modbus TCP

포트: 502

데이터: Holding Registers (16-bit)
