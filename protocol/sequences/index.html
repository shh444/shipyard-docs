    시퀀스¶

    1. Heartbeat 감시¶

    1. 로봇은 128 heartbeat를 주기적으로 갱신합니다.
    2. 팬던트는 161 heartbeat를 주기적으로 갱신합니다.
    3. 로봇이 팬던트 heartbeat를 일정 시간 받지 못하면 프로젝트 에러 151을 발생시킵니다.

    2. 용접 조건 다운로드¶

    1. 로봇이 153 = 1로 설정하여 조건 요청을 시작합니다.
    2. 팬던트가 221~255에 조건 값을 기록합니다.
    3. 필요 시 181~199의 보정/옵션 값도 함께 기록합니다.
    4. 팬던트가 154 = 1로 설정해 전송 완료를 알립니다.
    5. 로봇은 조건을 소비한 후 153, 154를 0으로 정리합니다.

    3. 터치 사이클¶

    1. 팬던트는 셀/플래그/기억 사용 여부를 171~180에 설정합니다.
    2. 로봇은 현재 터치 대상 정보를 155, 156에 공개합니다.
    3. 터치 완료 시 157을 사용해 완료 상태를 전달합니다.
    4. 이전 터치 재사용이 필요하면 180 = 1을 사용합니다.

    4. 용접 실행 중 상태 공개¶

    • 로봇 상태: 129~140
    • 실시간 전류/전압: 131~134, 212~213
    • 용접 종료: 137
    • 용접기 오류: 216

    5. 반환 완료 처리¶

    1. 로봇이 복귀를 완료하면 240 = 1을 올립니다.
    2. 작업 시트 메모 기준으로, 관련 요청 처리(예: 154 확인) 후 240을 0으로 다시 내립니다.

    6. 권장 구현 체크리스트¶

    • heartbeat timeout 시간을 문서 외부 설정값으로 명확히 둘 것
    • 153/154/240 클리어 주체를 PLC/로봇/팬던트 중 하나로 확정할 것
    • bitfield 레지스터는 정수 비교가 아닌 마스크 연산으로 구현할 것
    • 190~198은 프로젝트 시트 우선 구간이므로 실장비 검증 후 freeze 할 것
