로봇 → 펜던트 주소 맵

로봇에서 펜던트로 전송되는 상태 정보

주소 범위: 128 ~ 160
레지스터 수: 33개
데이터 방향: Read Only
업데이트: 10ms 주기

통신 상태

주소 신호명 데이터 타입 범위 단위 설명
128 하트비트 UINT16 0 ~ 65535 - 로봇 통신 상태 확인용 카운터. 주기적으로 증가

로봇 상태

주소 신호명 데이터 타입 값 설명
129 프로그램 동작여부 UINT16 0: 정지
1: 동작		 로봇 프로그램 실행 상태
130 용접 여부 UINT16 0: 대기
1: 용접중		 현재 용접 진행 상태
137 용접 종료 UINT16 1: 종료 용접 작업 종료 신호
141 로봇 준비 UINT16 1: 준비중 로봇 초기화 및 준비 상태
142 로봇 에러 UINT16 0: 정상
1: 에러		 로봇 에러 발생 플래그

용접 데이터

주소 신호명 데이터 타입 범위 단위 스케일링 설명
131 현재 전류 UINT16 0 ~ 600 A × 1A 실시간 용접 전류 피드백
132 현재 전압 UINT16 0 ~ 800 V × 0.1V 실시간 용접 전압 피드백
(예: 250 = 25.0V)
133 지령 전류 UINT16 0 ~ 600 A × 1A 설정된 목표 전류값
134 지령 전압 UINT16 0 ~ 800 V × 0.1V 설정된 목표 전압값

예제: 전압 값 변환

// 레지스터 값: 235
// 실제 전압 = 235 × 0.1V = 23.5V

voltage_raw = modbus_read(address=132)
voltage_actual = voltage_raw * 0.1  // 23.5V

PATH 정보

주소 신호명 데이터 타입 값 설명
135 현재 PATH 셀 UINT16 VL1, VL2, VR1, VR2, HOR 현재 작업 중인 용접 셀 위치
136 현재 PATH UINT16 1 ~ 5 현재 실행 중인 PATH 번호
138 전체 중 현재 PATH UINT16 0 ~ 7 전체 PATH 중 현재 진행 순서
139 전체 PATH UINT16 1 ~ 7 전체 PATH 개수
140 2F 개수 UINT16 1 ~ 3 2F (Two Face) 용접 개수

📝 PATH 셀 코드

  • VL1: Vertical Left 1
  • VL2: Vertical Left 2
  • VR1: Vertical Right 1
  • VR2: Vertical Right 2
  • HOR: Horizontal

주소 신호명 데이터 타입 단위 설명
143 현재 시간 UINT16 초(s) 현재 작업 경과 시간
144 전체 시간 UINT16 초(s) 전체 작업 예상 시간

아크센싱

주소 신호명 데이터 타입 설명
145 아크센싱 적분 INT16 아크센싱 적분값 (위치 보정 계산용)
146 아크센싱 보상 INT16 아크센싱 보상값 (실시간 위치 조정)

추가 정보

주소 신호명 데이터 타입 설명
149 TEMP_ROB_WELDER UINT16 로봇-용접기 간 임시 데이터
150 TEMP_PEND_WELD UINT16 펜던트-용접 간 임시 데이터

통신 제어

주소 신호명 데이터 타입 값 설명
153 용접 조건 요청 UINT16 1: 요청 로봇이 펜던트에 용접 조건 요청
154 정보 수신 완료 UINT16 1: 완료 로봇이 데이터 수신 완료 확인

터치 센싱

주소 신호명 데이터 타입 값 설명
155 터치 셀 UINT16 VL1, VL2, VR1, VR2, HOR 터치 센싱 대상 셀
156 터치 번호 UINT16 1 ~ 4 터치 포인트 번호
157 터치 완료 UINT16 1: 완료 터치 센싱 완료 신호

시스템 버전

주소 신호명 데이터 타입 형식 설명
160 로봇 버전 UINT16 메이저.마이너.버그 로봇 소프트웨어 버전 정보
예: 0x0102 = v1.2

예제: 버전 파싱

version_raw = modbus_read(address=160)  // 0x0105

major = (version_raw >> 8) & 0xFF    // 1
minor = version_raw & 0xFF            // 5

print(f"로봇 버전: v{major}.{minor}")  // v1.5
