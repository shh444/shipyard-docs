# 2. Modbus 신호 정리

이 장은 UR 모드버스 서버의 General Purpose 영역의 사용하는 주소 `128~255`를 대분류별 표로 다시 정리한 페이지입니다.
비트형/packed 값은 3장을, UR 모드버스 서버의 기본 데이터 레지스터(`0, 1, 256~405`)는 5장을 참조합니다.

아래 사진 팬던트 <-> 로봇 프로그램 간의 모드버스 신호 매핑 입니다. 
```{figure} _static/images/modbus_signals_flow.png
---
width: 100%
alt: 프로그램-모드버스-팬던트 화면 매핑
---
프로그램/팬던트 화면과 Modbus 신호 매핑(요약)
```
