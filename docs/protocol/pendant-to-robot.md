## 구현 메모

- `171/172`는 작업 시트 기준으로 `1~8 = A,B,C,c,D,d,E,e` 매핑을 사용합니다.
- `178`은 셀 선택 bitfield, `179`는 EXT_FLAG bitfield 입니다.
- `190/192/194/196`은 팬던트 값이 `x10` 스케일로 저장됩니다.
- `198`은 바닥 각도를 코드값으로 저장합니다.
