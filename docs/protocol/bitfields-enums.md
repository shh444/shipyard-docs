## 곡블럭 옵션1 (188)

작업 시트 기준으로 **Longi 좌/우, 용접 방향, 항상 1 비트**를 포함하는 packed/bitfield 값입니다.

| Bit | 의미 | 비고 |
| --- | --- | --- |
| 1 | Longi 좌 | 값 메모: X / L / C / R |
| 3 | Longi 우 | 값 메모: X / L / C / R |
| 4 | 용접 방향 | 값 메모: 좌우 / 우좌 |
| 15 | 항상 1 | 고정 비트 |

## 곡블럭 옵션2 (189)

작업 시트 메모상 `시작 -> 구간1 (0~100)` 과 `구간1 -> 종료 (0~100)` 를 나누어 저장하는 packed 값입니다.

| 필드 | 의미 |
| --- | --- |
| 전반부 | 시작 -> 구간1 (0~100) |
| 후반부 | 구간1 -> 종료 (0~100) |
| bit15 | 항상 1 |
