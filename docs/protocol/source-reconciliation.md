## 판정 원칙

1. **프로젝트 구현에 실제로 사용되는 값**은 작업 시트를 우선합니다.
2. 작업 시트가 공란이면 PDF 정의를 참고하되, 즉시 구현하지 않고 `Reserved/TBD`로 유지합니다.
3. bitfield는 작업 시트가 더 상세하면 작업 시트 정의를 따르고, PDF의 보조 설명은 비고로 남깁니다.

## 아직 현장 확인이 필요한 항목

- 149 / 150 실제 사용 여부
- 190~199의 최종 주소 freeze
- 203의 의미가 정말 `와이어 정보`로 확정인지 여부
- 221 / 222 방향성(팬던트→로봇 vs 용접기→로봇)
- 223 / 224 사용 계획 여부
