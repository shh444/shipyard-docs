## 구현 메모

- `202`는 bitfield 제어 레지스터이며, 토치/정역인칭/가스체크/스틱체크를 포함합니다.
- `211`은 작업 시트 기준으로 **STICK/WCR 상태**가 핵심이고, PDF는 **bit8 heartbeat** 설명을 추가로 제공합니다.
- `203`은 PDF의 `용접 속도` 대신 프로젝트 시트의 `와이어 정보`를 우선 적용했습니다.
- `207~210`은 PDF에만 있으며 프로젝트 시트에서는 공란입니다.
